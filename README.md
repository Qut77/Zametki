# Заметки - Учебный проект. Онлайн сервис по ведению записей онлайн.

## На первых этапах создания проекта задумано:
- Возможность просматривать все заметки
- Возможность создания, редактирования и удаления заметок
- Авторизация пользователей: у каждого пользователя свои записи

## Как будет развиваться проект
В будущем в проект будет добавлено:
- возможность поиска записей по названию, тексту или тегам
- пагинация записей
- добавлена возможность создания тегов записей
